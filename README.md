# Pixar Sync — application Home Assistant

Synchronise le tableau de bord Pixar (fichiers, tableau, automatisation de recharge) depuis un dépôt GitHub privé, avec contrôle d'intégrité, sauvegardes et refus d'écraser les modifications manuelles.

Installation : **Paramètres → Applications → Installer une application → ⋮ → Dépôts**, puis ajouter `https://github.com/franckdavion/pixar-sync-app`.

Ce dépôt ne contient que le code de l'application. Aucun jeton ni aucune donnée de la maison : le jeton GitHub se saisit dans la configuration de l'application, dans Home Assistant.
